**How created:** Manually (just make a new file)

### 📄 `app/__init__.py` — The App Factory (Most Important File)
**How created:** Manually — this is the first file you write after the folder.  
**What it does:** Builds (creates) the Flask app. Think of it as the LEGO instruction manual.

```python
# app/__init__.py
from flask import Flask
from .extensions import db, login_manager, bcrypt, migrate, csrf
from .config import config_map

def create_app(config_name="development"):
    app = Flask(__name__)                          # Step 1: Create blank Flask app
    
    config_class = config_map[config_name]
    app.config.from_object(config_class)           # Step 2: Load settings from config.py
    
    db.init_app(app)                               # Step 3: Connect database
    login_manager.init_app(app)                    # Step 4: Enable login system
    bcrypt.init_app(app)                           # Step 5: Enable password hashing
    migrate.init_app(app, db)                      # Step 6: Enable migrations
    csrf.init_app(app)                             # Step 7: Enable CSRF protection
    
    # Step 8: Register all route blueprints
    from .routes.auth import auth_bp
    from .routes.student import student_bp
    from .routes.admin import admin_bp
    app.register_blueprint(auth_bp, url_prefix="/auth")
    app.register_blueprint(student_bp, url_prefix="/student")
    app.register_blueprint(admin_bp, url_prefix="/admin")
    
    return app                                     # Step 9: Hand back the complete app
```

**Why "factory pattern"?** So you can create different versions of the app (development, testing) without conflict.

---

### 📄 `app/extensions.py` — The Tools Box
**How created:** Manually — create before `__init__.py`  
**What it does:** Creates all the Flask "plugins" in one place, so any file can import them without circular import errors.

```python
# app/extensions.py
from flask_sqlalchemy import SQLAlchemy
from flask_login import LoginManager
from flask_bcrypt import Bcrypt
from flask_migrate import Migrate
from flask_wtf.csrf import CSRFProtect

db = SQLAlchemy()          # The database connector
login_manager = LoginManager()  # The login/logout manager
bcrypt = Bcrypt()          # The password hasher
migrate = Migrate()        # The database version controller
csrf = CSRFProtect()       # The form security guard
```

> **Why separate file?** If you put `db = SQLAlchemy()` inside `__init__.py` AND a model also imports from `__init__.py`, Python gets confused (circular import). This file breaks that cycle.

### 📄 `app/config.py` — The Settings File
**How created:** Manually  
**What it does:** Contains all app settings as Python classes. Dev settings vs Production settings are separate.

```python
# app/config.py
import os
from dotenv import load_dotenv
load_dotenv()   # Read the .env file

class Config:   # Base settings (shared by all)
    SECRET_KEY = os.environ.get("SECRET_KEY")         # Reads from .env
    SQLALCHEMY_DATABASE_URI = os.environ.get("DATABASE_URL")
    WTF_CSRF_ENABLED = True

    DEBUG = True           # Shows error details on screen

class ProdConfig(Config):  # Production extras
    DEBUG = False          # Hides errors from users

config_map = {
    "development": DevConfig,
    "production": ProdConfig,
    "default": DevConfig
}
```

### 📄 `app/models/event.py` — The Events Table
**How created:** Manually  
**What it does:** Defines the `events` table with all its columns.

```python
# app/models/event.py
from ..extensions import db
from datetime import datetime

class Event(db.Model):
    __tablename__ = "events"          # ← This becomes the SQL table name
    
    # Each db.Column = one column in the table
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(200), nullable=False)
    description = db.Column(db.Text, nullable=False)
    venue = db.Column(db.String(200), nullable=False)
    event_date = db.Column(db.DateTime, nullable=False)
    total_seats = db.Column(db.Integer, nullable=False)
    available_seats = db.Column(db.Integer, nullable=False)
    status = db.Column(db.String(20), default='draft')
    
    # Relationship: "one event has MANY registrations"
    registrations = db.relationship("Registration", backref="event", lazy="dynamic")
    
    @property
    def is_registration_open(self):
        # This is a Python property — acts like a column but isn't stored in DB
        return self.event_date > datetime.now() and self.available_seats > 0
```

**This is the equivalent of this SQL you already know:**
```sql
CREATE TABLE events (
    id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(200) NOT NULL,
    description TEXT NOT NULL,
    venue VARCHAR(200) NOT NULL,
    event_date DATETIME NOT NULL,
    total_seats INT NOT NULL,
    available_seats INT NOT NULL,
    status VARCHAR(20) DEFAULT 'draft'
);
```

### 📄 `app/models/registration.py` — The Junction Table
**How created:** Manually  
**What it does:** Links students to events. One row = "Student X registered for Event Y".

```python
# Key parts of registration.py
class Registration(db.Model):
    __tablename__ = "registrations"
    
    id = db.Column(db.Integer, primary_key=True)
    student_id = db.Column(db.Integer, db.ForeignKey("students.id"))  # ← FK to students
    event_id = db.Column(db.Integer, db.ForeignKey("events.id"))       # ← FK to events
    status = db.Column(db.String(20), default="pending")
    registered_at = db.Column(db.DateTime, default=datetime.utcnow)
    attendance_marked = db.Column(db.Boolean, default=False)
    
    # Unique constraint: same student can't register for same event twice
    __table_args__ = (
        db.UniqueConstraint("student_id", "event_id", name="uq_student_event"),
    )
```

### 📄 `app/routes/auth.py` — Login & Register
**How created:** Manually  
**What it does:** Handles the login form submission, checks password, creates session.

```python
# Simplified version of what auth.py does:
from flask import Blueprint, render_template, redirect, flash
from flask_login import login_user

auth_bp = Blueprint("auth", __name__)   # Create a "mini Flask app"

@auth_bp.route("/login", methods=["GET", "POST"])
def login():
    if request.method == "POST":
        email = request.form["email"]
        student = Student.query.filter_by(email=email).first()
        
        if student and student.check_password(request.form["password"]):
            login_user(student)                    # Give them a session
            return redirect("/student/dashboard")  # Send to dashboard
        else:
            flash("Wrong email or password", "danger")
    
    return render_template("auth/login.html")   # Show the login page
```

```python
@student_bp.route("/events/<int:event_id>/register", methods=["POST"])
def register_event(event_id):
    # 1. Lock the event row (prevents 2 people grabbing last seat)
    event = Event.query.with_for_update().get(event_id)
    
    # 2. Check if seats available
    if event.available_seats <= 0:
        flash("Event is full!", "warning")
        return redirect(...)
```

## 📁 `app/forms/` — The Form Validators

**How created:** Manually make the folder, then create files inside.  
**What it does:** Defines what a valid form looks like (required fields, email format, password length, etc.)

```python
# app/forms/auth_forms.py
from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField, BooleanField
from wtforms.validators import DataRequired, Email, Length

class StudentLoginForm(FlaskForm):
    email = StringField("Email", validators=[
        DataRequired(),     # Can't be empty
        Email()             # Must look like an email
    ])
    password = PasswordField("Password", validators=[
        DataRequired(),
        Length(min=6)       # At least 6 characters
    ])
    remember_me = BooleanField("Remember Me")
```

**Why use forms?** If you didn't use Flask-WTF forms and someone typed `<script>alert('hacked')</script>` in the email field, it could break your site. Forms automatically sanitize and validate input.

## 📁 `migrations/` — Database Version Control

**How created:** Run these commands in order:

```bash
# Step 1: Initialize migrations folder (only done ONCE ever)
flask db init
# → Creates: migrations/ folder with alembic.ini, env.py, versions/

# Step 2: Detect your model changes and create a migration file
flask db migrate -m "Initial migration"
# → Creates: migrations/versions/8eff212a90d5_initial_migration.py

# Step 3: Apply the migration (actually creates tables in MySQL)
flask db upgrade
# → Runs the SQL: CREATE TABLE students (...), CREATE TABLE events (...), etc.
```

**What's inside `8eff212a90d5_initial_migration.py`?**  
Auto-generated SQL instructions — you never write this file manually:
```python
# Auto-generated by flask db migrate — DO NOT edit manually
def upgrade():
    op.create_table('students', ...)    # Creates students table
    op.create_table('events', ...)      # Creates events table
    op.create_table('registrations', ...)

def downgrade():
    op.drop_table('registrations')      # Undo: deletes tables
    op.drop_table('students')
    op.drop_table('events')
```

## 🔑 The Golden Rule

> **If a folder has `__init__.py` inside it, Python treats it as a "package" (importable module).**  
> That's why every folder like `models/`, `routes/`, `forms/`, `utils/` has an `__init__.py`.  
> Without it, `from app.models import Student` would fail.  
> It can be empty — just having the file is enough.

```python
# app/__init__.py
# PURPOSE: The Application Factory — builds and wires up the entire Flask app.
# This function is called by run.py to create the app.

import os
from flask import Flask, render_template
from .config import config_map
from .extensions import db, login_manager, bcrypt, migrate, csrf


def create_app(config_name: str = "default") -> Flask:
    """Build and return the configured Flask application."""

    # 1. Create the Flask app instance
    app = Flask(__name__, template_folder="templates", static_folder="static")

    # 2. Load settings from config.py
    config_class = config_map.get(config_name, config_map["default"])
    app.config.from_object(config_class)

    # 3. Make sure uploads folder exists
    os.makedirs(app.config.get("UPLOAD_FOLDER", "app/static/uploads"), exist_ok=True)

    # 4. Attach all extensions to the app
    db.init_app(app)
    login_manager.init_app(app)
    bcrypt.init_app(app)
    migrate.init_app(app, db)
    csrf.init_app(app)

    # 5. Register route blueprints (each blueprint = one section of the app)
    from .routes.auth import auth_bp
    from .routes.main import main_bp
    from .routes.student import student_bp
    from .routes.admin import admin_bp

    app.register_blueprint(main_bp)                          # URL: /
    app.register_blueprint(auth_bp, url_prefix="/auth")      # URL: /auth/login etc.
    app.register_blueprint(student_bp, url_prefix="/student")# URL: /student/dashboard etc.
    app.register_blueprint(admin_bp, url_prefix="/admin")    # URL: /admin/dashboard etc.

    # 6. Register error pages (404, 403, 500)
    @app.errorhandler(404)
    def not_found(e):
        return render_template("errors/404.html"), 404

    @app.errorhandler(403)
    def forbidden(e):
        return render_template("errors/403.html"), 403

    @app.errorhandler(500)
    def server_error(e):
        return render_template("errors/500.html"), 500

    # 7. Inject app_name into ALL templates automatically
    @app.context_processor
    def inject_globals():
        from datetime import datetime
        return {"app_name": "CampusConnect", "current_year": datetime.now().year}

    # 8. Prevent browser caching of pages (security: back button after logout)
    @app.after_request
    def set_no_cache(response):
        response.headers["Cache-Control"] = "no-store, no-cache, must-revalidate, max-age=0"
        response.headers["Pragma"] = "no-cache"
        return response

    return app
```

```python
from flask_login import UserMixin
from ..extensions import db, bcrypt


class Admin(UserMixin, db.Model):
    __tablename__ = "admins"

    id = db.Column(db.Integer, primary_key=True, autoincrement=True)
    name = db.Column(db.String(100), nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False, index=True)
    password_hash = db.Column(db.String(255), nullable=False)

    def set_password(self, password: str) -> None:
        """Hash and store password. Never store plain text!"""
        self.password_hash = bcrypt.generate_password_hash(password).decode("utf-8")

    def check_password(self, password: str) -> bool:
        """Compare entered password against stored hash."""
        return bcrypt.check_password_hash(self.password_hash, password)

    def get_id(self) -> str:
        """Flask-Login needs this to identify user type in session."""
        return f"a_{self.id}"   # "a_" prefix = Admin (vs "s_" for Student)

    def __repr__(self):
        return f"<Admin {self.email}>"
```

```python
# app/models/student.py
# PURPOSE: Defines the 'students' table.
# Also contains the user_loader — Flask-Login calls this to get
# the current logged-in user from the database on every request.

from flask_login import UserMixin
from ..extensions import db, bcrypt, login_manager


class Student(UserMixin, db.Model):
    __tablename__ = "students"

    id = db.Column(db.Integer, primary_key=True, autoincrement=True)
    first_name = db.Column(db.String(50), nullable=False)
    last_name = db.Column(db.String(50), nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False, index=True)
    password_hash = db.Column(db.String(255), nullable=False)
    roll_number = db.Column(db.String(20), unique=True, nullable=False)

    # One student can have MANY registrations (one-to-many relationship)
    registrations = db.relationship(
        "Registration", backref="student", lazy="dynamic", cascade="all, delete-orphan"
    )

    def __init__(self, **kwargs):
        """Auto-hash password when creating a Student object."""
        password = kwargs.pop("password", None)
        super(Student, self).__init__(**kwargs)
        if password:
            self.set_password(password)

    def set_password(self, password: str) -> None:
        self.password_hash = bcrypt.generate_password_hash(password).decode("utf-8")

    def check_password(self, password: str) -> bool:
        return bcrypt.check_password_hash(self.password_hash, password)

    @property
    def full_name(self) -> str:
        return f"{self.first_name} {self.last_name}"

    def get_id(self) -> str:
        return f"s_{self.id}"   # "s_" prefix = Student

    def __repr__(self):
        return f"<Student {self.email}>"


# Flask-Login calls this function on EVERY request to get the logged-in user
@login_manager.user_loader
def load_user(user_id: str):
    """
    Given a user_id string from the session cookie,
    return the matching Student or Admin object from the database.
    """
    if user_id.startswith("a_"):           # Admin
        from .admin import Admin
        return db.session.get(Admin, int(user_id[2:]))
    elif user_id.startswith("s_"):         # Student
        return db.session.get(Student, int(user_id[2:]))
    return None
```

```python
from datetime import datetime, timezone
from ..extensions import db


class Event(db.Model):
    __tablename__ = "events"

    id = db.Column(db.Integer, primary_key=True, autoincrement=True)
    title = db.Column(db.String(200), nullable=False)
    description = db.Column(db.Text, nullable=False)
    venue = db.Column(db.String(200), nullable=False)
    event_date = db.Column(db.DateTime, nullable=False)
    total_seats = db.Column(db.Integer, nullable=False)
    available_seats = db.Column(db.Integer, nullable=False)

    # 'draft' = not visible to students, 'published' = visible
    status = db.Column(db.String(20), nullable=False, default="draft")

    # One event has MANY registrations
    registrations = db.relationship(
        "Registration", backref="event", lazy="dynamic", cascade="all, delete-orphan"
    )

    @property
    def is_registration_open(self) -> bool:
        """Can students still register? Check date AND seats."""
        now = datetime.now(timezone.utc).replace(tzinfo=None)
        return self.event_date > now and self.available_seats > 0

    def __repr__(self):
        return f"<Event '{self.title}'>"
```

```python
from datetime import datetime
from ..extensions import db


class Registration(db.Model):
    __tablename__ = "registrations"

    # Enforce: one student can NEVER register for the same event twice
    # Also add indexes for fast filtering in admin dashboard
    __table_args__ = (
        db.UniqueConstraint("student_id", "event_id", name="uq_student_event"),
        db.Index("idx_reg_status", "status"),
        db.Index("idx_reg_student", "student_id"),
        db.Index("idx_reg_event", "event_id"),
    )

    id = db.Column(db.Integer, primary_key=True, autoincrement=True)

    # Foreign Keys: link to students and events tables
    student_id = db.Column(
        db.Integer,
        db.ForeignKey("students.id", ondelete="CASCADE"),
        nullable=False
    )
    event_id = db.Column(
        db.Integer,
        db.ForeignKey("events.id", ondelete="CASCADE"),
        nullable=False
    )

    # Status flow: pending → approved → attended
    #              pending → rejected
    #              approved → cancelled
    status = db.Column(db.String(20), nullable=False, default="pending", index=True)

    remarks = db.Column(db.Text, nullable=True)          # Admin notes
    registered_at = db.Column(db.DateTime, default=datetime.utcnow, nullable=False)
    approved_at = db.Column(db.DateTime, nullable=True)
    cancelled_at = db.Column(db.DateTime, nullable=True)
    attendance_marked = db.Column(db.Boolean, default=False, nullable=False)

    def __repr__(self):
        return f"<Registration Student:{self.student_id} Event:{self.event_id} [{self.status}]>"
```

```python
from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField, BooleanField
from wtforms.validators import DataRequired, Email, Length, EqualTo

    password = PasswordField("Password", validators=[DataRequired()])

    first_name = StringField("First Name", validators=[DataRequired(), Length(max=50)])
```

```python
# app/routes/main.py
# PURPOSE: Handles the public home page (no login needed).
# Also redirects logged-in users to their dashboards.

from flask import Blueprint, render_template, redirect, url_for
from flask_login import current_user
from ..models import Event, Student, Admin
from ..extensions import db

main_bp = Blueprint("main", __name__)   # No url_prefix — this handles "/"


@main_bp.route("/")
def index():
    """
    Home / landing page.
    - If already logged in → redirect to dashboard
    - Otherwise → show upcoming events and stats
    """
    if current_user.is_authenticated:
        if isinstance(current_user, Admin):
            return redirect(url_for("admin.dashboard"))
        return redirect(url_for("student.dashboard"))

    # Fetch upcoming published events for the landing page
    upcoming_events = (
        Event.query
        .filter_by(status="published")
        .order_by(Event.event_date.asc())
        .limit(6)
        .all()
    )
```

```python
auth_bp = Blueprint("auth", __name__)   # Registered with url_prefix="/auth" in __init__.py


@auth_bp.route("/register", methods=["GET", "POST"])
def register():
    """Student registration page."""
    if current_user.is_authenticated:
        return redirect(url_for("student.dashboard"))

            db.session.commit()
            login_user(student)
            flash("Account created! Welcome!", "success")

@auth_bp.route("/login", methods=["GET", "POST"])
def login():
    """Student login page."""
    if current_user.is_authenticated:
        return redirect(url_for("student.dashboard"))

    form = StudentLoginForm()
    if form.validate_on_submit():
        student = Student.query.filter_by(email=form.email.data.lower().strip()).first()
        if not student or not student.check_password(form.password.data):
            flash("Invalid email or password.", "danger")
            return render_template("auth/login.html", form=form)

        login_user(student, remember=form.remember_me.data)
        next_page = request.args.get("next")
        return redirect(next_page if next_page and next_page.startswith("/") else url_for("student.dashboard"))

    return render_template("auth/login.html", form=form)
```

```python
# app/routes/student.py
# PURPOSE: All student actions — dashboard, browse events, register/cancel.

from flask import Blueprint, render_template, redirect, url_for, flash, request
from flask_login import login_required, current_user
from functools import wraps

from ..extensions import db
from ..models import Event, Registration

student_bp = Blueprint("student", __name__, url_prefix="/student")


def student_required(f):
    """Custom decorator: only Students can access these routes."""
    @wraps(f)
    @login_required
    def decorated_function(*args, **kwargs):
        if current_user.__class__.__name__ != "Student":
            flash("Access denied.", "danger")
            return redirect(url_for("main.index"))
        return f(*args, **kwargs)
    return decorated_function


@student_bp.before_request
@student_required
def before_request():
    """This runs before EVERY student route — protects all pages at once."""
    pass


@student_bp.route("/dashboard")
def dashboard():
    """Student's home page after login."""
    upcoming_registrations = current_user.registrations.join(Event).filter(
        Event.event_date > db.func.now()
    ).order_by(Event.event_date.asc()).limit(3).all()

    recent_events = Event.query.filter(
        Event.event_date > db.func.now(), Event.status == "published"
    ).order_by(Event.event_date.asc()).limit(5).all()

    return render_template("student/dashboard.html",
                           upcoming_registrations=upcoming_registrations,
                           recent_events=recent_events)


@student_bp.route("/events")
def events():
    """Browse all upcoming events with search."""
    search = request.args.get("search", "")
    page = request.args.get("page", 1, type=int)

    query = Event.query.filter(Event.event_date > db.func.now(), Event.status == "published")

    if search:
        query = query.filter(
            Event.title.ilike(f"%{search}%") | Event.description.ilike(f"%{search}%")
        )

    events_page = query.order_by(Event.event_date.asc()).paginate(page=page, per_page=9)
    registered_ids = {r.event_id for r in current_user.registrations.all()}

    return render_template("student/events.html",
                           events_page=events_page,
                           registered_ids=registered_ids,
                           search=search)


@student_bp.route("/events/<int:event_id>")
def event_detail(event_id):
    """Single event detail page."""
    event = db.session.get(Event, event_id)
    if not event:
        flash("Event not found.", "warning")
        return redirect(url_for("student.events"))
    registration = current_user.registrations.filter_by(event_id=event.id).first()
    return render_template("student/event_detail.html", event=event, registration=registration)


@student_bp.route("/events/<int:event_id>/register", methods=["POST"])
def register_event(event_id):
    """Register current student for an event."""
    # with_for_update() = database LOCK — prevents 2 students grabbing last seat
    event = Event.query.with_for_update().get(event_id)

    if not event or not event.is_registration_open:
        flash("Registration is closed or event is full.", "warning")
        db.session.rollback()
        return redirect(url_for("student.events"))

    if current_user.registrations.filter_by(event_id=event.id).first():
        flash("You are already registered for this event.", "info")
        db.session.rollback()
        return redirect(url_for("student.event_detail", event_id=event.id))

    # Deduct seat and create registration in one atomic transaction
    event.available_seats -= 1
    reg = Registration(student_id=current_user.id, event_id=event.id, status="approved")
    db.session.add(reg)
    db.session.commit()   # ← This SAVES both changes to database at once

    flash(f"Successfully registered for {event.title}!", "success")
    return redirect(url_for("student.event_detail", event_id=event.id))


@student_bp.route("/my-registrations")
def my_registrations():
    """Show all events the student has registered for."""
    registrations = current_user.registrations.join(Event).order_by(
        Event.event_date.desc()
    ).all()
    return render_template("student/my_registrations.html", registrations=registrations)


@student_bp.route("/registrations/<int:reg_id>/cancel", methods=["POST"])
def cancel_registration(reg_id):
    """Cancel a registration and free up the seat."""
    reg = db.session.get(Registration, reg_id)
    if not reg or reg.student_id != current_user.id:
        flash("Registration not found.", "danger")
        return redirect(url_for("student.my_registrations"))

    if reg.event.is_registration_open:
        event = Event.query.with_for_update().get(reg.event_id)
        event.available_seats += 1    # Give the seat back
        db.session.delete(reg)
        db.session.commit()
        flash("Registration cancelled.", "success")
    else:
        flash("Cannot cancel registration for past events.", "warning")

    return redirect(url_for("student.my_registrations"))
```
